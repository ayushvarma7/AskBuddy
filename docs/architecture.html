Module inventory

ModuleResponsibility
slack_listener.pySocket Mode entry point; event handlers, approval buttons, startup wiring
agent.pyCugaSupervisor and every sub-agent; prompts; tool factories by risk tier

retrieve.pyCorpus-scoped hybrid retrieval: pgvector + full-text, merged by RRF, re-weighted by feedback
citations.pyDeterministic Source(s) validation against real corpus metadata
eval_curate.pyTurns negative feedback into committed regression tests
ratelimit.pyPer-user throttle and daily request ceiling
lifecycle.pyBackground-service health registry and graceful shutdown
logging_setup.pyCorrelation IDs and text/JSON log formatting
db.pyConnection pool, idempotent DDL, every query helper
ingest.pyChunking, embedding, incremental corpus ingestion
scheduler.pyRecurring reminders on a persistent Postgres job store
github_client.pyGitHub REST client with retry, rate-limit guard, write audit logging
git_watch.py / git_digest.pyProactive triage polling and scheduled repo digests
feedback.pyBlock Kit feedback UI and persistence
feedback_report.py / feedback_digest.pyAnalytics CLI and weekly Slack digest
